Developer API

Everything the app does is available over REST and a websocket. Authenticate with an API key and drive bots, sessions and messages programmatically.

1 · Create a key

Open the portal → Account → API keys → Create. The secret is shown once. Send it as x-api-key: bk_… or Authorization: Bearer bk_….

2 · Example

# List your bots
curl {{CLOUD}}/v1/bots -H "x-api-key: bk_your_key"

# Send a message to a bot's session
curl -X POST {{CLOUD}}/v1/sessions/<sessionId>/messages \
  -H "x-api-key: bk_your_key" -H "content-type: application/json" \
  -d '{"text":"summarize the top story on news.ycombinator.com"}'

# Stream events (websocket)
wscat -c "{{CLOUDWS}}/v1/stream?token=bk_your_key"

3 · Endpoints

Method Path Description
GET /auth/config Whether Google sign-in is configured (public).
GET /auth/me The authenticated user (plan, role).
GET /v1/config Capabilities, sandbox, node-online, usage.
GET /v1/bots List bots and groups.
POST /v1/bots Create a bot.
GET /v1/sessions List conversations with transcripts.
POST /v1/sessions/:id/messages Send a message; returns the updated session and task.
GET /v1/stream Websocket of realtime events (deltas, tasks, approvals).
GET /v1/skills Built-in capability packs.
GET /v1/learned-skills The shared learned-skill library.
GET /v1/api-keys List your API keys (prefix only).
POST /v1/api-keys Create a key (secret returned once).
DELETE /v1/api-keys/:id Revoke a key.
GET /v1/billing Current plan and whether Stripe is configured.
