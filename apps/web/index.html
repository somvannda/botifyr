FAQ

Frequently asked

Does it really operate software, or just talk about it?

It really operates: browser use, desktop computer use, and a code/shell sandbox — each task runs in a throwaway, isolated environment, and consequential steps wait for your approval.

Where does my data live?

Botifyr is self-hostable. Cloud hides secrets with envelope encryption; self-hosting keeps everything in your own database and volumes.

Which models can I use?

It's model-agnostic — any OpenAI-compatible provider. The default is a cost-efficient model with strict token caps, history summarisation and a response cache.

How do bots learn new skills?

A bot can save a capability it worked out. Once approved, it joins a shared library so new users' bots start already trained.

Can I sign in from the web, or only the desktop app?

Both. Use the desktop app for computer use, or sign in at botifyr.xyz/login to drive your agents from any browser.
