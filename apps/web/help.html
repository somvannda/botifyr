Getting started

Install the desktop app, then sign in with Google in your browser. When you return, the app picks up the session automatically. On first launch you get a default bot called Botifyr.

Bots & group chats

A bot is an agent plus its own conversation. Click ＋ to create a bot (name, colour, instructions) or a group chat that combines several bots, each replying in turn. Open a bot's panel (the ▢ button) for Details, Library, and its Computer screen.

Connect apps

From the footer, Connect apps opens the Marketplace. Connecting Gmail, Calendar or Drive lets your agents read and act on them. You authorize with the provider and can disconnect at any time.

Your computer

Turn on My computer to let a task use your own browser and shell instead of the cloud sandbox. Consequential actions still ask first unless you set Always allow.

Schedules

Edit a bot and set an Always-on schedule: a prompt and an interval. Botifyr runs it automatically and the result appears in the bot's conversation.

Settings

Click your avatar → Settings. General (account, theme, language, timezone), Computer (approvals, connection), Usage & Billing, Updates, and Vault (encrypted secrets).

Usage & cost

Every model call is capped and counted. The app shows Usage today; the cloud enforces a per-user rate limit and warns when you pass your daily token budget (it never blocks). Old turns are summarised so long chats stay cheap.

Self-hosting

The stack runs anywhere Docker does.

git clone <your-repo>
npm install
docker compose up -d --build cloud   # cloud + Postgres
npm run dev:desktop:tauri            # desktop app

Configuration lives in apps/cloud/.env (provider, keys, limits).
